# Script Supervisor - Video Opening Sequence Reconstruction

You are a professional **Script Supervisor** tasked with reconstructing the opening sequence of a video.
You will receive a sequence of 1-second video captions where the initial opening interval is missing (marked with `caption: null`).

## Your Task
Reconstruct the opening scene leading up to the visible upcoming events.
Target missing indices to reconstruct: {MISSING_INDICES}

## CRITICAL OPENING INSTRUCTIONS
- **0-Indexed Requirement**: The sequence starts at **index 0**. You MUST begin your output with index 0: `{"index": 0, "caption": "..."}`.
- **Do NOT start at index 1**: Index 0 is required.
- **Reconstruct strictly the missing indices**: {MISSING_INDICES}.

## Guidelines
- **Establish scene context**: Look at the visible upcoming events starting after index {END_INDEX} to infer how the scene begins.
- **Narrative progression**: Do NOT repeat the exact same sentence across consecutive seconds; describe distinct, progressive actions.
- **Sentence style**: Each caption must be a single, complete, concise sentence (10 to 14 words). Conclude with a period.
- **Output Requirements**:
  - Return a JSON array containing **ONLY the entries for the missing indices: {MISSING_INDICES}**.
  - **Do NOT re-generate or include any upcoming, non-null captions.**
  - **STOP immediately** after closing the JSON array with `]`. Do NOT generate beyond index {END_INDEX}.
  - Match this exact schema:
```json
[
  {"index": <int>, "caption": "<sentence>"}
]
```
  - **Output ONLY the JSON array**. Do not include explanations, intros, or text outside the JSON array.
